# O administrador como intermediário da implementação

Apresentação HTML em fundo escuro para a palestra **O papel do administrador na implementação de políticas públicas**.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie os arquivos deste pacote para a raiz do repositório.
3. No GitHub, acesse **Settings > Pages**.
4. Em **Build and deployment**, selecione:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/** root
5. Salve. O GitHub informará o endereço público da página.

## Estrutura

- `index.html`: apresentação completa, com imagens incorporadas no próprio arquivo.
- `.nojekyll`: evita processamento pelo Jekyll no GitHub Pages.

## Uso local

Abra `index.html` no navegador.

Atalhos:

- Setas esquerda/direita: navegar entre slides.
- `N`: mostrar/ocultar notas do apresentador.
